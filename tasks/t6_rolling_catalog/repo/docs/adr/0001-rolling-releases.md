# ADR-0001. Старые и новые кассы работают одновременно

При выпуске версии операторский процесс обновляет схему первым. Некоторые
кассовые процессы продолжают работать прежней версией. При откате оператор
возвращает прежний бинарник и оставляет текущую БД.

После миграции клиент предыдущей версии должен по-прежнему уметь открыть
каталог, читать товары и записывать их. Новые клиенты должны видеть изменения
старых клиентов. Новые данные, для которых у старого клиента нет поля, при
записи старым клиентом должны сохраняться. До окончания периода отката нельзя
удалять или переименовывать используемые старым клиентом таблицы и колонки.
