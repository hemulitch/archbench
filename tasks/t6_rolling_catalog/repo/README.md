# Каталог для касс

Каталог хранится в локальной SQLite. Воркеры печати и операторский процесс
пользуются одним файлом. Публичные функции лежат в `catalog/catalog.py`.
`open_catalog(path)` открывает базу и применяет миграции.

Тесты запускаются командой `python -m pytest tests -q`.
Архитектурные решения находятся в `docs/adr/`.
