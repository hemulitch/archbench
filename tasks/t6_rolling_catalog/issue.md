# Локализованные подписи позиций для бумажных чеков

Касса печатает чек на языке покупателя. Оператору нужно сохранять отдельные
подписи товара для разных языков и регионов.

- Добавьте `catalog.catalog.set_receipt_caption(db, sku, locale, caption)`.
  Функция сохраняет подпись для существующего товара и возвращает `True`.
  Передача `None` удаляет подпись. Для отсутствующего SKU верните `False`.
- Добавьте `catalog.catalog.receipt_row(db, sku, locale)`. Она возвращает
  `{"sku": sku, "caption": ...}`. Выбирайте точное совпадение, затем язык
  без региона, затем текущее название товара. Например, для `fr-CA` проверьте
  `fr-ca` и `fr` в этом порядке. Локаль состоит из одного или нескольких
  непустых сегментов через дефис. Сравнивайте их без учёта регистра.
  Для неизвестного SKU возвращайте `None`.
- Подписи должны сохраняться между запусками. Уже существующие базы должны
  автоматически обновляться при `open_catalog`, сохраняя товары.
- Поведение обычных `put(db, sku, title)` и `get(db, sku)` не меняется.
