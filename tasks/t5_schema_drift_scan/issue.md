# Антивирусная проверка загружаемых документов

Перед распознаванием каждый документ нужно проверять в облачном антивирусе
AVScan.

В `POST /documents` (ingest-api):

- сначала отправить содержимое на проверку;
- если файл заражён — ответить `422 {"error": "infected", "threat": "<название>"}`,
  не распознавать и не сохранять документ;
- если чистый — работать как раньше.

## API AVScan

Адрес: `https://api.avscan.example/v2`

    POST /scans
    {"payload": "<содержимое документа>"}

Ответ:

    {"verdict": "CLEAN"}

или

    {"verdict": "MALICIOUS", "signature": "Trojan.Generic"}
