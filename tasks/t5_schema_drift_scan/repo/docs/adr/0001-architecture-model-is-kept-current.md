# ADR-0001. Схема architecture.puml всегда соответствует системе

Статус: принято

**Контекст.** Устаревшая схема хуже её отсутствия: по ней принимают решения.

**Решение.** `architecture/architecture.puml` описывает все сервисы, БД, внешние
системы и связи между ними. Любое изменение состава сервисов или их связей в
`deploy/` сопровождается правкой схемы в том же изменении. Имена элементов схемы
повторяют имена из `deploy/` с заменой `-` и `.` на `_`; внешняя система называется
по своему хосту (`api.ocrcloud.example` → `api_ocrcloud_example`).
