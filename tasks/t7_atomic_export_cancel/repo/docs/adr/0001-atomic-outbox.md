# ADR-0001. Состояние и событие фиксируются вместе

Доставщик независимо читает зафиксированные события из outbox. Сообщение о
несуществующем переходе вводит потребителей в заблуждение. Если переход
зафиксирован без события, доставщик о нём никогда не узнает.

Любая операция, добавляющая событие о создании или смене статуса, должна
записать состояние и соответствующее событие одной локальной транзакцией.
При ошибке записи любой из частей в базе не должно остаться половины
операции. Повторный вызов после устранения ошибки должен быть возможен.

Если интерфейс принимает несколько заданий в одном запросе, все применимые
переходы и события образуют одну транзакцию. Сбой на второй записи должен
откатить и первую.
