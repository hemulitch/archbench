# Фоновые выгрузки

`exports/store.py` хранит задания в SQLite. `submit` выдаёт ID, `status`
читает текущее состояние, `complete` завершает задание из очереди. Отдельный
доставщик читает ленту `events` из таблицы `outbox`.

Тесты запускаются командой `python -m pytest tests -q`.
Архитектурные решения находятся в `docs/adr/`.
