# atomicOutbox

Функциональные тесты проверяют поток без сбоев. Архитектурный сценарий
использует три независимых прогона на временных БД. SQLite прерывает запись
события при создании задания, запись события при отмене и смену статуса при
отмене. После каждого сбоя второй клиент проверяет зафиксированные данные.
Сценарий также снимает сбой и повторяет запрос, чтобы проверить, что одна
ошибка не застревает в состоянии задания.

При пакетной отмене сценарий даёт первому заданию записать своё событие,
затем блокирует событие второго задания. Проверяет, что не отменилось даже
первое задание и что повтор запроса фиксирует оба перехода.
