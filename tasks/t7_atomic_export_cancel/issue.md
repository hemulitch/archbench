# Отмена выгрузки, которая ещё в очереди

Оператору нужно отменять выгрузки, которые больше не нужны.

- Добавьте в `exports.store` функцию `cancel(db, export_id)`. Она возвращает
  `True`, если выгрузка перешла из `queued` в `cancelled`.
- При повторной отмене, отсутствующем ID или статусе `completed` функция
  возвращает `False` и ничего не меняет.
- При переходе добавьте одно событие с `kind="export.cancelled"` в ленту
  `events(db)`. Разным выгрузкам соответствуют разные `export_id`.
- Завершение отменённой выгрузки не должно переводить её в `completed`.

Оператор также может выбрать несколько выгрузок. Добавьте
`cancel_batch(db, export_ids)`. Она принимает итерируемую последовательность
ID и возвращает список фактически отменённых выгрузок в порядке первого
появления ID. Повторы, отсутствующие задания и задания вне очереди
пропускаются. События соответствуют списку и идут в том же порядке.
