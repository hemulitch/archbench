# Месячный лимит начисления баллов по уровню клиента

Нужно ограничить, сколько баллов клиент может получить за календарный месяц.

Лимиты зависят от уровня клиента:

| Уровень | Лимит баллов в месяц |
| ------- | -------------------- |
| basic   | 1000                 |
| silver  | 3000                 |
| gold    | 10000                |

Месяц определяется по `occurred_at`.

Что должно измениться в `POST /accruals` (loyalty-api):

- если начисление целиком укладывается в остаток лимита, оно проходит как раньше;
- если не укладывается, начисляется только остаток, а ответ содержит
  `accepted_points` и `rejected_points`;
- если лимит уже исчерпан, начисление записывается с нулём: `accepted_points = 0`,
  ответ всё равно `201`;
- `rejected_points` есть в ответе всегда (при полном начислении равно 0).

Покупки приходят параллельно с нескольких касс. Одновременные запросы не должны
приводить к превышению лимита.
