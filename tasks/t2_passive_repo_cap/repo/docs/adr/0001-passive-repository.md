# ADR-0001. Сервисы-репозитории пассивны

Статус: принято

**Контекст.** Когда репозиторий начинает обращаться к другим сервисам, в слое
хранения появляется бизнес-логика, а транзакции зависят от чужой доступности.

**Решение.** Сервис с меткой `repo` имеет единственную исходящую связь — со своей
БД. Всё, что нужно ему для операции, вызывающий сервис передаёт в параметрах.
Доступ к БД есть только у сервиса-репозитория.
