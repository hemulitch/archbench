# ADR-0001. Внешние системы подключаются через адаптеры

Статус: принято

**Контекст.** У каждого внешнего провайдера своя модель данных, коды ошибок и
темп изменений. Когда доменный сервис обращается к провайдеру напрямую, эта
модель расползается по нашему коду.

**Решение.** Связь с внешней системой имеет только сервис-адаптер (ACL). На один
внешний провайдер — один адаптер с меткой `acl` в `deploy/<имя>.yaml`. Адаптер
переводит модель провайдера в нашу и наружу отдаёт API в наших терминах.

**Следствие.** Смена провайдера или формата затрагивает один сервис.
