# boundedWorkingMemory

Функциональные тесты проверяют значения отчёта и стабильный порядок при
равенстве. Архитектурный сценарий оценивает пиковые Python-аллокации через
`tracemalloc` при обработке 2 000 и 60 000 записей, с одинаковым `limit=5`.
Вход генерируется по одной записи. Допустимый прирост пика составляет 512 КиБ.
Сценарий проверяет, что обе выборки прочитаны целиком. Он измеряет аллокации
Python в заданном сценарии, поэтому не даёт формального доказательства
сложности и не измеряет память нативных библиотек.
