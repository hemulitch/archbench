# Отчёт по показаниям счётчиков

`metering/summary.py` читает строки NDJSON и считает итоги. Каждая запись
содержит `meter` (строка), `tick` (целое число) и `watts` (целое число).

Для исходного отчёта запустите `python -m metering.summary readings.ndjson`.
Функции отчётов принимают произвольный итерируемый источник записей, включая
одноразовый генератор. Тесты запускаются командой `python -m pytest tests -q`.
Архитектурные решения находятся в `docs/adr/`.
