# ADR-0001. Размер входного потока не определяет расход памяти

На одном воркере обрабатываются файлы от нескольких тысяч до миллионов
записей. Источник может быть одноразовым. Новые отчёты читают источник один
раз и не хранят ранее прочитанные записи, кроме тех, которые нужны для
выдачи результата. Если клиент запросил ограниченный список размера k, память
может расти с k, но при фиксированном k не должна расти с длиной входа.
