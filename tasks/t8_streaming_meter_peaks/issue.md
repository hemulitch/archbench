# Показать самые мощные замеры в отчёте

В отчёте по замерам электросчётчиков сейчас есть число записей и сумма
значений. Оператору нужен ещё список крупнейших замеров.

Добавьте `summarize_with_peaks(readings, *, limit=5)` в `metering.summary`.
Она принимает тот же вход, что и `summarize(readings)`. Возвращаемый словарь
содержит `count`, `total_watts` и новый ключ `peaks`:

- `peaks` содержит до `limit` исходных записей в порядке убывания `watts`.
- При одинаковых `watts` запись, пришедшая раньше, располагается раньше.
- При `limit=0` список пустой, но итоги по всем замерам всё равно считаются.
  Отрицательный `limit` вызывает `ValueError`.
- `summarize` сохраняет старый формат ответа.
