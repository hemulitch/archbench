# ADR-0001. Модули общаются только через контракты

Статус: принято

**Контекст.** Монолит планируется разделять по модулям. Это возможно, только если
модули не знают внутреннее устройство друг друга.

**Решение.** Код модуля может импортировать из другого модуля только его
`contracts.py`. Всё в `internal/` и прочие файлы модуля — его личное дело. Если
контракту не хватает операции, её добавляет в контракт модуль-владелец.
