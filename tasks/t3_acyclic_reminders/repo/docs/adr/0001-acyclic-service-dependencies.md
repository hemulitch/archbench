# ADR-0001. Зависимости между сервисами ацикличны

Статус: принято

**Контекст.** Сервисы, которые вызывают друг друга, нельзя выпускать и понимать
по отдельности, а отказ одного сразу распространяется на другой.

**Решение.** Граф синхронных зависимостей между сервисами остаётся без циклов.
`bookings-api` вызывает `notifications-api`, обратного направления нет. Данные,
нужные нижестоящему сервису, передаёт вышестоящий.
